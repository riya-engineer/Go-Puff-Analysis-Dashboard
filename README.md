# 🛵 Gopuff Dashboard | Power BI

## 📖 Overview

The **Gopuff Dashboard** is an interactive Power BI report that provides a comprehensive view of business performance through key performance indicators (KPIs) and dynamic visualizations. It enables users to monitor sales metrics, analyze category performance, and identify business trends to support data-driven decision-making.

---

## 🎯 Project Objectives

- Monitor overall business performance.
- Track key sales and operational KPIs.
- Analyze category-wise distribution.
- Identify trends and performance variations.
- Present business insights through interactive dashboards.

---

## 📊 Dashboard Highlights

### Key Performance Indicators (KPIs)

- 📈 Total Sales
- 💰 Total Revenue
- 📦 Total Orders
- 👥 Total Customers

### Visualizations

- 📊 Clustered Column Chart
- 🍩 Donut Chart
- 🥧 Pie Chart
- 📉 Waterfall Chart
- KPI Cards
